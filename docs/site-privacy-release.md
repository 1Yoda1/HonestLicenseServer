# Проект единого документа для /privacy/ — не утверждено, не публиковать

Этот файл хранится вне site/. Он не является публичной политикой или офертой.
Проект составлен по фактической цепочке: JSON POST → SQLite ConnectionRequests →
защищённый admin API → HonestDesk. SMTP исключён; Max пока не подключён.
IP и User-Agent сохраняются в БД, но не выдаются в список HonestDesk.
Стандартный веб-сервер может дополнительно вести журналы;
их реальные настройки необходимо подтвердить, а не описывать как установленный факт.

## Проект текста единой политики

### 1. Общие положения и оператор

Политика определяет порядок обработки персональных данных посетителей сайта
honestflow.ru, направляющих заявку на техническое обслуживание кассового рабочего
места, а также правила конфиденциальности этих данных. Оператор: [подтверждённое
наименование/ФИО, необходимые реквизиты, адрес]. Обращения по вопросам персональных
данных принимаются по [подтверждённый адрес и контакт]. Политика относится к заявкам
сайта; обработка данных в приложении и при исполнении договора определяется
применимыми документами и не включается в неё автоматически.

### 2. Субъекты, цели, данные и основания

Субъекты — индивидуальные предприниматели и контактные лица юридических лиц,
которые сами обращаются за обслуживанием. Для рассмотрения обращения, обратной связи,
уточнения оборудования и согласования индивидуальных условий используются имя,
телефон, город, наименование компании, количество рабочих мест, модели ККТ и текст
обращения. API также принимает необязательные email и наименование товароучётной
системы; текущая форма эти отдельные поля не запрашивает. Не следует направлять
паспортные, платёжные, специальные категории данных, сведения о здоровье и данные
третьих лиц, не нужные для заявки. Обработка для рекламы в эту цель не входит.
Основание обработки: [утверждённое основание для каждой категории субъектов;
при согласии — самостоятельное согласие, которое не подменяется принятием политики].

Для предотвращения злоупотреблений и обеспечения работы формы сервер получает
IP-адрес, User-Agent, источник заявки и время обращения. Основание, необходимый
объём и сроки обработки технических сведений: [утверждённое решение]. При согласии
сохраняются его точный текст, версия, серверное время получения, основание и версия
политики для подтверждения условий обращения.

### 3. Порядок обработки, хранения и передачи

Заявка передаётся серверу методом POST и сохраняется в базе данных. Используются
сбор, запись, систематизация, накопление, хранение, извлечение, использование,
уточнение, предоставление уполномоченным получателям, блокирование и уничтожение
в пределах утверждённых целей и регламентов. При настроенной почте уполномоченный
получатель получает уведомление с контактными и деловыми сведениями заявки, её
комментарием и временем. IP и User-Agent в уведомление не включаются.
Места хранения, обработчики по поручению, получатели и условия их доступа:
[подтверждённый перечень, страны, назначения передачи]. Трансграничная передача:
[подтверждённое положение]. Данные не предназначены для публичного распространения.

### 4. Сроки и прекращение обработки

Для ответа на заявку данные хранятся [срок или определённый критерий и предельный
срок]. При заключении договора дальнейшая обработка производится на применимом
основании и в предусмотренные сроки. Технические сведения хранятся [срок];
доказательства согласия — [основание и срок]; почтовые копии, журналы и резервные
копии — [сроки и порядок очистки]. По достижении цели, истечении срока либо отзыве
согласия при отсутствии иного законного основания данные блокируются/уничтожаются
в сроки, предусмотренные законом и утверждённым регламентом. Обработка не продолжается
лишь потому, что заявка технически осталась в базе.

### 5. Конфиденциальность и защита

Доступ предоставляется только лицам, которым сведения нужны для согласованных
задач, с обязанностью сохранять конфиденциальность. Оператор применяет необходимые
правовые, организационные и технические меры защиты, проверяет доступ и действия
обработчиков, обеспечивает восстановление и своевременное устранение нарушений.
Конкретные публично заявляемые меры должны соответствовать реально внедрённым.
Передача и раскрытие допускаются на применимом законном основании и в необходимом
объёме. Политика не ограничивает права субъекта и не освобождает оператора от
обязанностей, установленных законом.

### 6. Права и обращения

Субъект вправе получить информацию об обработке, требовать уточнения, блокирования
или уничтожения незаконно обрабатываемых либо ненужных данных, отозвать согласие,
потребовать прекращения обработки в предусмотренных законом случаях, обратиться
в Роскомнадзор или суд. Порядок подачи обращения: [контакт, способ идентификации,
перечень необходимых сведений, сроки ответа по действующему закону]. Отзыв не
отменяет законность обработки до отзыва; продолжение возможно только при наличии
иного предусмотренного законом основания. Актуальная редакция публикуется на
/ privacy / (без пробелов), версия [утверждённая версия и дата].

## Включение после утверждения

Разместить полные утверждённые тексты без квадратных скобок в конфигурации сервера
ConnectionRequestPrivacy: PrivacyPolicyText, PrivacyPolicyVersion, LegalBasis.
Для Consent дополнительно ConsentText, ConsentVersion. Затем Enabled=true.
До этого публичный GET не возвращает черновики, POST возвращает 503, кнопка формы
недоступна. PreContract допустим только после подтверждения применимости основания
ко всем принимаемым категориям заявителей; в этом режиме checkbox не показывается.
При изменении текстов обязательно менять версии. Точный текст полученного согласия
сохраняется в заявке; архив утверждённых политик с версиями нужно хранить отдельно.
Сайт и API требуют совместного обновления. Старые отправители без версии получат 409.
В site-config.js providerDetails можно добавить только проверенные публичные реквизиты
и контакты; сейчас пусто, вымышленные сведения не публикуются.
Caddyfile.example содержит 301 для старых URL, статические HTML-переходы работают
также без обновления Caddy. Никакие команды публикации этим изменением не выполняются.
site.zip не пересобирался и не является актуальным результатом этой задачи.
